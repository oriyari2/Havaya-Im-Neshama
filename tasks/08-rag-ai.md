# Task 01 - Project Setup

## Goal
Create the initial project skeleton for the system.

## Must Include
- backend folder for FastAPI
- desktop_client folder for PySide6
- rag folder for AI/RAG logic
- docker folder for docker-compose
- migrations folder for database scripts
- .env.example file
- README instructions

## Do Not Implement Yet
- Authentication
- Customers
- Activities
- Bookings
- Event Sourcing logic
- RAG answers

## Done When
- The folder structure exists
- FastAPI can start with a health check endpoint
- PySide6 opens a basic empty window
- docker-compose file exists
- README explains how to run the project
