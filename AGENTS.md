# AGENTS.md

## Project Rules

This project is a student final project for Windows Systems Engineering.

Always follow:
- docs/PRD.md
- tasks/current task file

Work task by task.
Do not implement future tasks unless explicitly requested.

## Tech Stack

- Backend: FastAPI
- Desktop client: PySide6
- Database: PostgreSQL / Supabase-compatible SQL
- AI/RAG: local or simple RAG module
- Architecture: MVC, CQRS, Event Sourcing where relevant

## Coding Rules

- Keep the implementation simple and readable.
- Prefer clear folder structure over clever abstractions.
- Add only the files needed for the current task.
- Do not skip README instructions.
- Do not implement authentication, customers, activities, bookings, dashboard, or RAG unless the current task asks for it.

## After Each Task

Explain:
- what was created
- how to run it
- what files were changed
- what the next task should be
